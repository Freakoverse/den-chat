# Security Policy

DEN Chat is a decentralized, end-to-end encrypted client for the Nostr protocol.
It handles users' private keys and encrypted communications, so we take security
seriously — while being upfront that the project is in **alpha** and has not yet
had a formal third-party audit.

## Reporting a vulnerability

**Please report security issues privately.** Do not open a public issue or pull
request, or post about it publicly, before it has been fixed.

**Preferred:** send an **encrypted Nostr DM** to the maintainer:

```
npub1lw0alc5n7gpgc9hv7n230zcump7p63a8atfgf23d6gcxvqykm5xqqqmduf
```

You can DM this npub from DEN Chat itself, or from any Nostr client.

**Alternative:** if private vulnerability reporting is enabled on this repository,
use **Security → Report a vulnerability** on GitHub.

### What to include

- A description of the issue and its impact.
- Steps to reproduce (a proof-of-concept if possible).
- The affected version/commit and platform (web / Windows / Linux).
- Any suggested remediation.

Please give us a reasonable chance to investigate and ship a fix before public
disclosure (coordinated disclosure). We're a small team — we'll acknowledge as
quickly as we can.
